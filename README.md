# runway

A Claude Code plugin marketplace.

## Installation

```
/plugin marketplace add <your-org>/runway
```

## Plugins

| Plugin | Description |
|--------|-------------|
| [blueprint](./plugins/blueprint/README.md) | Intent producer + invariant referee: `design → spec → ⟦any coding agent implements⟧ → verify → commit`. |

### blueprint

Install:

```
/plugin install blueprint@runway
```

See [`plugins/blueprint/README.md`](./plugins/blueprint/README.md) for the artifact definitions (design vs spec), the pipeline, and the full skill list.
